# FOH Engineer

**Status:** draft  
**Owner:** Tech Lead  
**Last reviewed:** 2026-08-12

## Purpose

Create a clear, comfortable congregational mix that prioritizes vocals and the lyric.

## Owns

- House mix for the service
- System alignment checks within published SOP
- Coordinating with MD on dynamic shape
- Protecting the room from damaging levels

## Pre-service

- [ ] Walk system: mains, subs, fills as applicable
- [ ] Load correct show file / snapshot plan
- [ ] Line check with stage
- [ ] Gain structure sane before effects
- [ ] Talk to MD about sparse vs full moments

## Mix priorities (default)

1. Lead vocal intelligibility  
2. Groove (kick/snare/bass relationship)  
3. Supporting vocals  
4. Harmony instruments  
5. Sparkle / FX  

## During service

- Anticipate transitions; don’t chase every peak with the same aggression
- Keep a written or mental note list for debrief
- If something is truly broken, communicate to stage/MD calmly

## Post

- [ ] Save show file if changed intentionally
- [ ] Note phantom problems for Tech Lead
- [ ] Power-down per strike checklist
