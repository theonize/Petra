# Stream / Broadcast Operator

**Status:** draft  
**Owner:** Tech Lead  
**Last reviewed:** 2026-08-12

## Purpose

Deliver a stable, clear online experience that matches the in-room service as faithfully as practical.

## Owns

- Encoder / platform health
- Broadcast audio mix (or coordination with dedicated broadcast mixer)
- Camera shading / switching per SOP
- Lower-thirds and online-only graphics if used
- Start/stop and contingency when platform fails

## Pre-service

- [ ] Platform authenticated / destination correct
- [ ] Audio meters healthy (no reverb-only vocal disaster)
- [ ] Recording enabled if required
- [ ] Backup stream path known

## Norms

- Chat moderation is a **separate** role unless explicitly combined
- Never experiment with production routing after doors if avoidable
