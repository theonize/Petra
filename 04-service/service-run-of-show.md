## Spine (customize)

1. Building open / tech power path  
2. Team call time  
3. Line check + pre-service rehearsal  
4. Team prayer  
5. Doors / pre-service atmosphere  
6. Service start (countdown or live open)  
7. Worship set / liturgical pieces per plan  
8. Transitions to word, ordinances, response  
9. Closing song / benediction support as planned  
10. Post-service play-out (optional)  
11. Strike + debrief notes
