# Purchase & Repair

**Status:** draft  
**Owner:** Tech Lead + Worship Lead  
**Last reviewed:** 2026-08-12

## When something breaks

1. Make safe  
2. Note impact on next service  
3. Log: item, symptom, last known good, urgency  
4. Temporary workaround if qualified  
5. Repair vs replace decision with budget owner  

## Purchases

- Follow church finance process (quotes, PO, approved vendors)
- Prefer standardizing models already in inventory
- Document new gear in inventory + SOP updates if workflow changes

## Urgency levels

| Level | Example | Response |
|---|---|---|
| P1 | No pastor mic path | Fix before doors |
| P2 | One IEM pack dead, spares exist | Same week |
| P3 | Cosmetic / nice-to-have | Planned batch |
