# Communication Norms

**Owner:** Director  

## Channels (fill with your real tools)

| Channel | Use for | Not for |
|---|---|---|
| **Planning tool** (Planning Center / equivalent) | Schedules, plans, attachments | Long pastoral debates |
| **Team chat** (GroupMe/Slack/etc.) | Day-of logistics, quick confirms | Sensitive correction |
| **Email** | Longer policy updates | Urgent Sunday morning changes |
| **SMS / call** | True urgencies | Routine chart drops |
| **In person** | Feedback, conflict, care | — |

*Replace tool names in [`11-reference/tools-and-systems.md`](../11-reference/tools-and-systems.md).*

## Response expectations

| Situation | Expected response |
|---|---|
| Schedule request | Accept/decline within **48 hours** |
| Swap request | Reply within **24 hours** |
| Day-of emergency | Call/text immediately; don’t only post in a quiet thread |
| Chart/key change midweek | Acknowledge once you’ve seen it |

## Tone

- Short, specific, kind
- Put decisions in writing in the planning tool when they affect Sunday
- Public channels: no sarcasm about people or the congregation
