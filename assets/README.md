# Assets

Diagrams, stage plot images, logo marks, and other binaries.

## Guidelines

- Prefer SVG/PNG; keep files reasonably small
- Name clearly: `stage-plot-main-default.png`
- No photos of minors without appropriate releases/policy
- No credential screenshots
