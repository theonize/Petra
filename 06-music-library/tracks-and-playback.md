# Tracks & Playback

**Status:** draft  
**Owner:** Worship Lead + Tech Lead  
**Last reviewed:** 2026-08-12

## When we use tracks

- Thin band Sundays
- Specific production moments
- Click/guide for consistency

## Rules

1. Playback owner named on the plan.
2. Guide/click in IEMs; congregation shouldn’t hear count-ins.
3. Arrangement on chart matches track form.
4. Failure plan: band can finish without tracks.

## Tech notes

- Interface / laptop power locked down
- Output routing documented
- Sample rate matches session standard
- Redundant copy of session on second drive when critical
