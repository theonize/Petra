## Source of truth

The plan’s attached chart + stated key/tempo beat any random YouTube memory.

## Chart standards

- Section labels match what Worship Lead calls (`V1`, `PC`, `C`, `V2`, `B`, `T`, `E`)
- Repeats and tags explicit
- Capo notation clear for guitars
- Lyric sheet synced for media

## Keys

- Choose for congregation first, leader second, ego never
- Publish key early enough for vocalists to flag trouble
- If capoing creates chaos, prefer a real key change chart

## Tempos

- BPM published when click/tracks used
- Feel notes welcome (“straight”, “half-time chorus”, “push”)
