# Midweek Rehearsal Runbook

**Status:** draft  
**Owner:** MD + Tech Lead  
**Last reviewed:** 2026-08-13

*Times below are placeholders — set to your real clock.*

## Default timeline

| Time | Block | Owner |
|---|---|---|
| T-0:15 | Tech open / line check; **house + confidence** up | Tech (all scheduled) |
| T-0:00 | Call time — band on stage | All (band **and** tech) |
| T+0:10 | Devotions / frame the night (short) | Worship Lead or MD |
| T+0:15 | Priority song 1 (hardest or opener) — slides live | MD + Media |
| … | Work list by difficulty / transition risk | MD |
| T+1:20 | Full set run (or partial if time) — full production path | MD + Tech |
| T+1:40 | Notes + prayer | MD / Worship Lead / Tech Lead |
| T+1:50 | Strike / reset as needed | All |

## Who is expected

- **Every band/vocalist** scheduled for the linked service
- **Every tech** scheduled for the linked service (FOH, monitors, media, lights, stream as rostered)
- Same attendance rule: no prior rehearsal → default do not serve ([`rehearsal-standards.md`](rehearsal-standards.md))

## MD working order (suggested)

1. Songs with new forms or tracks  
2. Multi-song transitions  
3. Vocal stack polish  
4. Comfort songs last  

## Tech parallel track

- Stabilize gains early
- **Media:** run **overhead (house) and confidence** for the working set — same deck mindset as Sunday
- Freeze cosmetic mix tweaks until musical form settles
- Capture input list **and** slide/deck fixes before leaving
- Confirm confidence readability from key stage positions during at least one full song

## Slides at practice (must)

| Feed | Rehearsal expectation |
|---|---|
| House / overhead | On and advanced with the set |
| Confidence monitors | On; band/vocals use them (stands only if already excepted) |
| Stream | As needed for training / critical weekends |

Do not “save the real slides for Sunday.” Rehearsal is where timing and form bugs die.

## Attendance note

This midweek block is the default **prior rehearsal** for the linked Sunday — **musicians and tech**. Who is present (or formally released) is who leaders plan to put on the roster — see [`rehearsal-standards.md`](rehearsal-standards.md).
