# Rehearsal Standards

**Status:** draft  
**Owner:** MD + Tech Lead  
**Last reviewed:** 2026-08-12

## Purpose

Rehearsal is for **ensemble** problems — blend, transitions, tech, and feel — not for first exposure to the songs.

## Policy (must)

1. Personal practice happens before group rehearsal.
2. Call time means ready: tuned, patched, mic’d, app open, water filled.
3. Phones don’t run the room; emergency use only during runs.
4. Notes are normal; defensiveness slows everyone down.
5. If you will be late or absent, notify MD/Tech Lead ASAP.

## Preparation bar

| Role | Before walking in |
|---|---|
| Vocals | Parts learned; marked chart |
| Band | Changes known; patches set |
| FOH/Monitors | Show file staged; input list current |
| Media | Deck ordered to plan |

## Etiquette

- Talk between songs, not over the MD
- Tune quietly; fix buzzes without a TED talk
- Guests and kids on stage only if planned and safe
- Leave food/drinks away from consoles and snakes

## What “rehearsed enough” means

- Forms are stable
- Entrances are clean
- Loud/soft map is shared
- Tech can execute without heroics
- Team can pray without panic
