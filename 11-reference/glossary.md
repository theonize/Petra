# Glossary (extended)

See also [`00-foundation/definitions.md`](../00-foundation/definitions.md).

| Term | Meaning |
|---|---|
| **Confidence monitor** | Screen musicians/speakers face on stage |
| **Matrix** | Console mix-minus or special bus (e.g. stream feed) |
| **Mix minus** | Feed without a source that would cause echo/loop |
| **Patch** | Physical or digital routing connection |
| **Scene / snapshot** | Saved console state |
| **Snake** | Multi-channel cable run stage ↔ FOH |
| **DI** | Direct input box (instrument to console) |
| **RF** | Wireless radio management |
| **Strike** | Tear-down after event |
| **Green room** | Offstage waiting/prep area |
| **Downstage / upstage** | Toward congregation / toward back wall |
| **Busking** | Live freestyle console changes (use sparingly) |
