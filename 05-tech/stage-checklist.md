# Stage Checklist

**Owner:** Stage / Logistics · Tech Lead  

Minimum viable Sunday: **nothing to trip on · spare mic, cable, and DI where the plot says · inputs match the list.**

## Pre

- [ ] Plot matches who is actually playing this week
- [ ] Labels on inputs match the FOH input list
- [ ] Cables taped / ramped; pathways clear for pastoral moments and altar calls
- [ ] Spare SM58, cable, DI, and batteries in the known location ([Our Congregation](../10-templates/our-congregation.md))
- [ ] Stands, stools, water, towels; tablet mounts only for cleared exceptions
- [ ] Quick-change instrument plan agreed with players
- [ ] Hands off at **freeze** unless safety/failure

## Service

- [ ] Mic swaps and handoffs done quietly, from the side
- [ ] Watch the Platform lead for pastoral moments that need the platform cleared

## Post

- [ ] Strike and reset per [Strike & Storage](../09-equipment/strike-and-storage.md)
- [ ] Report damaged cables / missing spares to the Tech Lead
