# FOH Checklist

**Status:** draft  
**Owner:** FOH / Tech Lead  
**Last reviewed:** 2026-08-12

## Pre

- [ ] Power path complete (console, processing, amps/powered speakers)
- [ ] Correct show file loaded
- [ ] Clock/click feed verified if used
- [ ] Wireless scan / fresh batteries plan
- [ ] Talkback to stage working
- [ ] Line check: each input passes, labeled, phantom as needed
- [ ] Walk the room: rough system check
- [ ] Mute groups / VCAs make sense for the set
- [ ] Spare vocal mic path ready

## Service

- [ ] Service start snapshot / safe state known
- [ ] Speaking mics prioritized for pastoral moments
- [ ] Notes captured for debrief

## Post

- [ ] Save intentional file changes with date note
- [ ] Batteries out of spares that need it / charge dock filled
- [ ] Console parked per SOP
- [ ] Issues logged
