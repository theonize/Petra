# FOH Checklist

**Owner:** FOH / Tech Lead  

Minimum viable Sunday: **pastor mic works · lead vocal clear at the back · nothing hurts · hands off at freeze.** Then the list.

## Pre

- [ ] Power path complete, in order (console, processing, amps/powered speakers last)
- [ ] Correct show file loaded
- [ ] Clock/click feed verified if used
- [ ] Wireless scan / fresh batteries plan
- [ ] Talkback to stage working
- [ ] Line check: each input passes, labeled, phantom (= extra power some mics need) only where needed
- [ ] **Pastor / speaking mic passes** and a spare handheld is live on a known channel
- [ ] Walk the room: rough system check; hearing protection where it should be
- [ ] Mute groups / VCAs make sense for the set
- [ ] **Freeze** (default: doors) — called once on talkback with the Worship Lead; no more changes unless safety/failure

## Service

- [ ] Service start snapshot / safe state known
- [ ] Mix priority: spoken word → lead vocal → groove → the rest
- [ ] If anyone reports pain: turn down, then tell the Tech Lead
- [ ] Notes captured for debrief

## Post

- [ ] Save intentional file changes with date note
- [ ] Batteries out of spares that need it / charge dock filled
- [ ] Console parked / powered down in the documented order
- [ ] Issues logged
