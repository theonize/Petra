# Show File Standards

**Status:** draft  
**Owner:** Tech Lead  
**Last reviewed:** 2026-08-12

## Goals

Any trained operator should find a predictable file — not someone’s mysterious weekend science project.

## Conventions

- File names: `YYYY-MM-DD_Service_Descriptor` or seasonal template names
- Keep a **golden** template per room/service style
- Sunday changes that are improvements get merged back to golden midweek
- Experimental scenes live in clearly marked snapshots, not as the boot default

## Version hygiene

- Don’t overwrite golden without a note
- Export/backup before major firmware changes
- Document plugin/processor dependencies

## Access

Who may edit golden files: Tech Lead + designated FOH operators.
